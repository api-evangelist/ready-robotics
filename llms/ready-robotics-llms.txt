# READY Robotics

> READY Robotics was an industrial-automation software company (Columbus, Ohio, founded 2016, spun out
> of Johns Hopkins University) that built Forge/OS, a universal operating system for industrial robots.
> **The company ceased operations in August 2024** and every developer-facing host it ran has been
> withdrawn from DNS. There is no callable API, no live documentation, and no machine-readable contract.

This file was generated by API Evangelist from a third-party profile of the company's remaining public
surface. It was NOT published by READY Robotics.

## Status

- Company status: defunct (operations ceased August 2024; wound down via an assignment for the benefit
  of creditors, with equipment auctioned 13-15 August 2024).
- Live API surface: none.
- Machine-readable contract: none reachable. Forge Edge advertised a REST API with an OpenAPI/Swagger
  description and Python / JavaScript / C++ clients, but that reference lived on
  developer.ready-robotics.com, which no longer resolves.
- Marketing site: https://www.ready-robotics.com/ resolves through Cloudflare but answers every
  request, including agent requests, with an interactive JavaScript challenge (HTTP 403). The domain
  carries no MX record.

## Withdrawn hosts (all NXDOMAIN as of 2026-08-26)

- developer.ready-robotics.com — developer portal and Forge Edge API reference
- docs.ready-robotics.com — Forge/OS product documentation
- market.ready-robotics.com — Forge/OS app marketplace
- portal.ready-robotics.com — customer portal
- support.ready-robotics.com — support and knowledge base
- kb.ready-robotics.com, labs.ready-robotics.com, ecosystem.ready-robotics.com,
  download.ready-robotics.com, dev.ready-robotics.com

## What still exists

- GitHub organization: https://github.com/ready-robotics — public, 58 repositories, predominantly
  vendored upstream C++ dependencies (ZeroMQ, spdlog, protobuf, yaml-cpp, libmodbus, ROS-Industrial
  packages) that Forge/OS was built on.
- RAL2 sample driver: https://github.com/ready-robotics/ral2-sample-driver — first-party C++/Qt plugin
  template implementing the `ral2::Driver` interface for Forge/OS 5.5.0, with device-configuration
  JSON, URDF/SRDF robot models and Qt translation files. Version 0.1.0, last pushed 2024-05-17,
  default branch `experimental`. Source distribution only; not published to any package registry.
- https://ready-robotics.github.io/ — GitHub Pages for the "READY User Documentation" repository, now
  serving only the string "Hello World".

## Products (historical, no longer sold or supported)

- Forge/OS — robot operating system presenting one low-code programming surface across robot models
  from ABB, Epson, FANUC, Kawasaki, Stäubli, Universal Robots and Yaskawa.
- Forge Edge — REST API and data-stream layer over Forge/OS, documented with OpenAPI/Swagger.
- RAL2 (Robot Abstraction Layer 2) — the C++/Qt driver plugin interface for adding robot support.
- Forge Station / Forge Ctrl — hardware controllers bundling Forge/OS.
